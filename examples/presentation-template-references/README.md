# Presentation template references

This directory contains unpacked reference material for Presentation template
research. It is not an installed template catalog and is not an authoring
runtime.

## Collections

- `kimi/`: thirty user-provided visual-reference sets. Each set contains the
  original `design.md` and `reference.jpg` pair.
- `codex/`: seven public MIT-licensed presentation template packages from the
  pinned `office-artifact-tool` reference revision. Each package includes its
  guide, metadata, preview, and editable `reference.pptx`.

Reference material may be inspected or used as clean-room calibration input.
It must not be mistaken for a current OfficeKit Template Skill, selected by
template search, or shipped as an executable layout system.
