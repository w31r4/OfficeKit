# Pop Geometry

## Communication territory

A playful geometric language with controlled energy, large type, and shapes that carry meaning.

Use this style for youthful campaign deck, creative education, community event. Avoid it for earnings filing, safety incident review.

This is a visual direction, not a page library. Read the calibration images for hierarchy, rhythm, and relationships. Build every slide from the current content and do not trace sample geometry or reuse sample wording.

## Design grammar

- **Composition:** Use one oversized geometric action per page and balance it with a clear information zone.
- **Typography:** Friendly heavy sans-serif type supports short statements; body text remains calm and readable.
- **Geometry and surface:** Use circles, zigzags, cropped blocks, and deliberate collisions, but assign each shape a compositional role.
- **Evidence:** Charts can use bold categorical color when the number of series stays small and labels remain direct.
- **Imagery:** Choose joyful real-world imagery or simple original illustration; avoid generic smiling stock groups.
- **Recurring motif:** One migrating dot or cutout may connect sections without becoming a sticker set.
- **Density:** Use a medium default, then vary it intentionally between orientation, proof, and decision pages.
- **Palette roles:** Treat #FFF3D6 as the base field, #182335 as primary ink, #FF4F79 as the decisive accent, #00A6A6 as supporting evidence, and #FFC857 as quiet structure. Adapt values when a user design system is authoritative.

## Page behavior

- Give every page one audience task, one claim, and one primary visual carrier.
- Derive new page silhouettes from this grammar. Do not repeat one arrangement across the deck.
- Keep charts, diagrams, images, and typography in one information relationship; do not place them as independent decorations.
- Use native editable PowerPoint objects and licensed or user-provided imagery. Render and review every page.

## Avoid

- Random confetti.
- Six-color charts.
- Playfulness over clarity.
- Do not mix another template's visual language. A user-provided design system or reference deck remains authoritative.
- Do not copy the calibration text or coordinates; they demonstrate behavior, not reusable pages.
