# Silver Atelier

Use this style when premium portfolio. Documentary detail and narrow metallic accents create restrained value.

## Visual premise

- Build the page around the **atelier** motif; repeat it sparingly so the deck feels related without repeating one layout.
- Use **#F2F3F3** as the main field, **#171717** for primary type, **#9A6B45** for the decisive signal, **#C4A35A** for secondary evidence, and **#C9CDCF** for rules or context.
- Keep density **sparse**. an expressive proposition face paired with a practical workhorse face.
- imagery establishes context while numbers remain directly attributable.
- Use documentary product imagery as evidence or atmosphere; crop decisively and keep typography independent from busy detail.

## Composition

- Give each page one dominant reading path and vary the silhouette between cover, analysis, data, and decision pages.
- Use rules, axes, scale changes, and direct labels before reaching for repeated containers.
- Let negative space isolate the claim; do not leave space that has no focusing or pacing role.

## Avoid

- Do not use this style for incident review.
- Do not turn every fact into an equal card or badge.
- Do not add decorative motifs that compete with the evidence.

## Calibration

The examples are original fictional calibration pages. Recompose every real slide from its communication task; do not copy their coordinates or text.
