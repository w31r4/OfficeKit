# Presentation Template Creator

This plugin creates reusable OfficeKit presentation style Skills. It accepts a
complete style guide, four to six unrelated calibration-page images, and
optional reviewed clean-room PPJ/PPTX references, then packages the fixed
schema-v3 surface atomically with verified hashes.

External reference files, analysis evidence, and temporary decks remain inside
the OfficeKit task. A published template may contain its own rights-declared
OfficeKit-authored reference program/deck, never the external source, a fixed
layout registry, or executable page code.

Use the bundled `presentation-template-creator` Skill for the complete workflow.
