# Skill Update

This plugin provides a read-only impact checker for OfficeKit capability
changes. It maps changed runtime, protocol, Help, Skill, example, test, and
evidence paths to the consumer surfaces that need review. It does not edit
files, load a codec, contact a provider, or decide whether a feature is ready.

Use the bundled `skill-update` Skill and its `check-primitive-impact.mjs`
script from the repository root.
