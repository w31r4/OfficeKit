# Scenario routing

Choose one primary scenario from the audience's job, not from a desired color
or visual fashion. Add at most one secondary scenario when a real second job
changes the narrative or evidence treatment.

| Primary scenario | Use when the audience must | Guide |
| --- | --- | --- |
| Analysis and decision | compare evidence and choose | [analysis-decision](analysis-decision.md) |
| Business proposal | approve an offer, investment, or plan | [business-proposal](business-proposal.md) |
| Management report | align on performance, risk, and action | [management-report](management-report.md) |
| Academic research | evaluate a question, method, and result | [academic-research](academic-research.md) |
| Education and training | understand, practice, and retain | [education-training](education-training.md) |
| Technical engineering | understand a system and operate it safely | [technical-engineering](technical-engineering.md) |
| Brand and creative | remember a promise and choose to engage | [brand-creative](brand-creative.md) |

The scenario guide supplies communication and visual tendencies, not a fixed
palette or page template. User brand authority, a selected Template Skill, and
the current deck's Design Grammar decide the actual visual language.

Do not blend several scenario guides to make a generic compromise. If the deck
contains a proof page inside a brand launch or a training appendix inside a
technical handoff, borrow that page's evidence rule locally while keeping the
primary deck identity intact.
