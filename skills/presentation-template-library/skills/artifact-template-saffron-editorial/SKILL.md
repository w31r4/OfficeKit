# Saffron Editorial

Use this style when trend magazine. Long-form argument and bold photography alternate around one saffron signal.

## Visual premise

- Build the page around the **margin** motif; repeat it sparingly so the deck feels related without repeating one layout.
- Use **#E9E6DF** as the main field, **#111111** for primary type, **#E4B91E** for the decisive signal, **#D64055** for secondary evidence, and **#77726B** for rules or context.
- Keep density **dense**. an expressive proposition face paired with a practical workhorse face.
- imagery establishes context while numbers remain directly attributable.
- Use documentary industrial imagery as evidence or atmosphere; crop decisively and keep typography independent from busy detail.

## Composition

- Give each page one dominant reading path and vary the silhouette between cover, analysis, data, and decision pages.
- Use rules, axes, scale changes, and direct labels before reaching for repeated containers.
- Let negative space isolate the claim; do not leave space that has no focusing or pacing role.

## Avoid

- Do not use this style for technical protocol.
- Do not turn every fact into an equal card or badge.
- Do not add decorative motifs that compete with the evidence.

## Calibration

The examples are original fictional calibration pages. Recompose every real slide from its communication task; do not copy their coordinates or text.
