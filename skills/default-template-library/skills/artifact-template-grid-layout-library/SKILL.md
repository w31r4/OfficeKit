# Grid Layout Library

Use this template only after template search selects it or the user names it.
Keep the retained reference unchanged.

## Workflow

1. Read `artifact-template.json` and inspect `assets/preview.png`.
2. Load the Presentations template workflow and materialize a distinct working
   copy of `assets/reference.pptx`.
3. Select only the source pages whose content roles fit the requested deck.
   The 26-page reference is a layout library, not the required output sequence.
4. Reuse supported source slides, replace instructional content with sourced
   user content, and preserve the chosen pages' hierarchy and spacing.
5. Vary adjacent silhouettes. Replace gray media placeholders with relevant
   evidence or imagery rather than leaving them as decoration.
6. Reimport, render, review, and return a distinct final PPTX.

## Boundaries

This is an opinionated, light, monochrome grid system. Do not select it for a
dark direction, brand-creative or image-led work, or when an authoritative user
template or brand system exists. A failed template operation does not authorize
rebuilding the deck through another engine.
