# Grid Layout Library

## Communication territory

Use this explicit scaffold for evidence-led reports that benefit from a
measured editorial grid: research notes, structured comparisons, operating
briefs, and modular handouts. It is a visual grammar, not a command to reuse
the same page silhouette. Do not select it for an immersive dark stage, a
brand-led launch, or an authoritative external template.

## Visual grammar

Use a white or paper field, near-black type, one restrained blue signal, and
fine rules. Establish a small set of column guides and baseline intervals,
then let each page choose the columns it actually needs. The grid creates
alignment and rhythm; it must not become a wall of equal boxes. Titles are
conclusion-led, labels are short, and sources stay in a stable low-attention
position.

## Page vocabulary

- **Editorial opening:** proposition, scope, and a quiet structural mark.
- **Indexed evidence:** a chart, table, or map aligned to explicit guides.
- **Process strip:** a numbered sequence with real stages and evidence below.
- **Split comparison:** two different conditions on a shared baseline, not two
  decorative panels.
- **Closing ledger:** implication, unresolved question, and next action.

Native charts, tables, images, connectors, and text remain editable. A photo
region may occupy one or more grid columns when it supplies identity or
context. Keep line weight, text scale, and spacing consistent while varying
the page contour. Direct labels beat detached legends.

## Review

Check that every object aligns to a meaningful guide, every empty region has a
reading purpose, and no content is hidden by a neighboring line, image, or
annotation. Reject card walls, random geometry, repeated metric boxes, and
automatic Grid fallback. The included PPJ/PPTX is a source-bound migration of
the historical Grid reference; use it for inspection or explicit continuation,
not as a fixed clone. Recompose, render, and re-import every final deck.
