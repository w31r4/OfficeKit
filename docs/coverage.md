Status meanings:

- **done**: the modeled OfficeKit operation is supported for creation/import, edit, export, and second import where applicable.
- **partial**: a narrower profile is editable, or imported content is preserved but some creation/editing is intentionally rejected.
- **unsupported**: no modeled operation is provided; Office export must fail rather than flatten the object if preservation cannot be proven.

## Gate policy

Daily `npm test` is the fast gate (`npm run test:fast`): it covers syntax/import, core Office/PDF model smoke, OfficeKit routing/reference-path/portability validators, Help, and package-content smoke without downloading external PDF providers or running full domain/reference Skill workflows or render matrices, clean-install, PromptBench, or the default-template/native matrix. `npm run test:slow` is the complete chain and is reserved for provider/runtime/native changes, PromptBench or default-template changes, release candidates, and nightly `ci-slow` runs; hosted `ci-slow` and release jobs invoke that same step table as ten named contiguous segments to keep each runner command bounded, then run `docs:api`, `test:pack`, release metadata, OfficeBridge, and platform NativeAOT gates. Real Excel/PowerPoint desktop acceptance is split into the Add-in lane `.github/workflows/windows-office-live.yml` and the three-deck lossless lane `.github/workflows/windows-pptx-lossless.yml`, both on `[self-hosted, windows, office]` runners. Their evidence validators reject macOS/mock results; GitHub-hosted Windows CLI and Add-in build smoke remain portable tests only. See [CI gate layering](ci-gates.md).

The attachment-quarantine audit contract is enforced at the validator boundary: an `extract-attachments` audit must directly repeat `validation.sourceUnchanged: true`, `validation.allHashesVerified: true`, `validation.allPathsContained: true`, `validation.duplicateNamesSeparated: true`, and the exact boolean `validation.attachmentsOpenedOrExecuted: false`, in addition to the manifest copies. Missing or incorrect values fail closed; pre-hardening matrices remain historical, while the current repeat is recorded below.

## Architecture

The current 2.0 Presentation boundary is the `Presentation Program JSON 2.0`
row below. Older rows that name a public Presentation facade, Compose,
`ctx.plan`, or JavaScript authoring are retained only as historical capability
evidence and are superseded by PPJ for product use.
