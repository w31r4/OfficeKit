# Codex presentation references

Source: the public MIT-licensed `office-artifact-tool` repository pinned at
`73c99c67ca7bbaa82cec0b158c647db583dcd970`.

Included presentation packages:

- `artifact-template-business-review`
- `artifact-template-market-trends-report`
- `artifact-template-operating-review`
- `artifact-template-project-kickoff`
- `artifact-template-simple-dark-mode`
- `artifact-template-simple-light-mode`
- `artifact-template-team-alignment`
- `artifact-template-grid-layout-library`

Each directory is an unpacked historical template reference, including its
editable PPTX. These packages are examples only: they are not installed,
searched, or treated as current PPJ templates. The upstream license is retained
as `LICENSE.md`.

The Grid Layout Library reference is recovered from the MIT-licensed OfficeKit
commit `2ebffcac` (source SHA-256
`3e9f8f2fc673e91a74227603ee8aa4abe67b0974ea4541a44db76abc97b55712`). It is
kept here as a historical native reference; the active schema-v3 package also
contains a source-bound PPJ projection and declares this license explicitly.
