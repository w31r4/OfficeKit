# Task-local style brief

The concise arm writes this short artifact before PPJ composition. It is a
working decision record, not a template or page skeleton.

```text
Goal: one sentence describing the audience change.
Visual thesis: the single visual idea that makes the claim memorable.
Primary carrier: image | chart | table | diagram | typography | native-vector | mixed.
Visual move: the concrete relationship made visible by scale, position, contour,
              connection, enclosure, crop, or contrast.
Reading order: 1 → 2 → 3, including what is deliberately secondary.
Visual DNA: palette roles, type roles, geometry/line language, surface hierarchy,
            image treatment, density rhythm, and one restrained motif.
Avoid: the specific default patterns that would weaken this page.
Review probes: the two or three visible failures that must be checked after render.
```

The brief may name a direction, but it MUST NOT prescribe fixed page coordinates,
reusable page code, layout IDs, or a generic card/container helper.
