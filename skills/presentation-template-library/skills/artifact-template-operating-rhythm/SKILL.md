# Operating Rhythm

## Communication territory

An operational field guide that makes time, ownership, and dependency legible at a glance.

Use this style for weekly operating review, program cadence, cross functional execution. Avoid it for luxury product launch, art exhibition.

This is a visual direction, not a page library. Read the calibration images for hierarchy, rhythm, and relationships. Build every slide from the current content and do not trace sample geometry or reuse sample wording.

## Design grammar

- **Composition:** Use a strong temporal axis, visible owners, and exceptions in context; do not split each metric into a separate tile.
- **Typography:** Condensed labels and tabular numerals support fast scanning; headlines name the operational consequence.
- **Geometry and surface:** Use lanes, ticks, dependency lines, and restrained status marks on an open field.
- **Evidence:** Show sequence, throughput, and bottlenecks; every status color needs a label or shape cue.
- **Imagery:** Use process photography only when it explains a constraint, handoff, or physical workflow.
- **Recurring motif:** A repeated cadence tick can orient weekly, monthly, and milestone pages.
- **Density:** Use a dense default, then vary it intentionally between orientation, proof, and decision pages.
- **Palette roles:** Treat #EEF2F1 as the base field, #12343B as primary ink, #E38B2C as the decisive accent, #2C7873 as supporting evidence, and #A8B8B5 as quiet structure. Adapt values when a user design system is authoritative.

## Page behavior

- Give every page one audience task, one claim, and one primary visual carrier.
- Derive new page silhouettes from this grammar. Do not repeat one arrangement across the deck.
- Keep charts, diagrams, images, and typography in one information relationship; do not place them as independent decorations.
- Use native editable PowerPoint objects and licensed or user-provided imagery. Render and review every page.

## Avoid

- Traffic-light wallpaper.
- Ownerless tasks.
- Decorative Gantt bars.
- Do not mix another template's visual language. A user-provided design system or reference deck remains authoritative.
- Do not copy the calibration text or coordinates; they demonstrate behavior, not reusable pages.

- **Data:** shows how evidence receives visual priority and direct annotation.
- **Closing:** shows how the direction compresses into a specific decision or next move.
