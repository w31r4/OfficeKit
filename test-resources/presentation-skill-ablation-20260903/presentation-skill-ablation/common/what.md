# What: Communication Contract

Use this layer before choosing a style or primitive.

1. Name the audience and the change the audience should make after the page.
2. State one claim in one sentence; separate facts, assumptions, and open
   questions.
3. Order evidence so the reader can answer “what changed?”, “why does it
   matter?”, and “what should happen next?” without speaker-only context.
4. Choose `reader`, `hybrid`, or `live` from the delivery setting. Do not add
   motion merely because the page can animate.
5. Set a content budget before drawing. A dense page may use more elements, but
   every element must support the claim or its reading path.

For 1-to-10 edits, preserve the existing page contract unless the request is a
redesign: audience task, claim, evidence, carrier, reading order, protected
objects, and layer order are the edit boundary.
