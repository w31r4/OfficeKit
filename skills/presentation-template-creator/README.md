# Presentation Template Creator

This plugin creates reusable OfficeKit presentation style Skills. It accepts a
complete, self-contained style guide, an OfficeKit-authored reference PPTX, and
four to six unrelated calibration-page images, then packages the fixed
presentation surface atomically with verified hashes. The guide is the design
authority, the native deck is an inspectable calibration/source asset, and the
images calibrate visual range. It is not intentionally compressed into a
palette summary.

External reference PPTX files, analysis evidence, and superseded temporary decks
remain inside the OfficeKit task. The published template contains guidance, one
OfficeKit-authored reference deck, and original images—not an external source
deck or a fixed-layout registry.

Use the bundled `presentation-template-creator` Skill for the complete workflow.
