# Six-sample programmable import evidence

This directory records measurements for six local PPTX references. The source
files stay in the ignored `tmp/reference-pptx-downloads/` directory and are not
part of Git or the npm package.

`manifest.v1.json` binds each filename to its source SHA-256, size, slide count,
package inventory, and rights note. `evidence.v1.json` records the current
OfficeKit head, exact no-op results, object classification totals, and a small
set of real table/image edits. It is evidence for the bounded profiles listed,
not a claim that every OOXML feature is editable.

The six files are two NASA NTRS technical presentations and four
SlidesCarnival references. Any redistribution or production use must follow the
source record and applicable attribution terms. No source slide bytes or media
are committed here.
