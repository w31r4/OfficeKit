# Presentation Template Creator

This plugin creates reusable OfficeKit presentation style Skills. It accepts a
distilled style guide and four to six unrelated calibration-page images, then
packages the fixed schema-v3 surface atomically with verified hashes.

Reference PPTX files, analysis evidence, and temporary decks remain inside the
OfficeKit task. The published template contains guidance and original images,
not source slides, layout code, or reusable page geometry.

Use the bundled `presentation-template-creator` Skill for the complete workflow.
